O que é Git Hub

O GitHub é uma plataforma online de hospedagem de código-fonte e arquivos que usa o sistema de controle de versão Git.

O que o GitHub faz?

  • Armazena códigos na nuvem: Funciona como um disco rígido online para seus projetos de programação.
  • Controla versões: Guarda o histórico de todas as alterações feitas nos arquivos.
  • Ajuda na colaboração: Permite que várias pessoas trabalhem no mesmo projeto ao mesmo tempo sem apagar o trabalho dos outros.
